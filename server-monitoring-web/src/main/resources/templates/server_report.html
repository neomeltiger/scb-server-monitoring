서버 점검 리포트 관리자가 요청할 때만 서버(svr_collect_client)가 점검해서 보냅니다

점검 분야
불러오는 중...

· 리포트는 관리자가 요청할 때만 만들어집니다 : [리포트 요청] (바로) 또는 자동 요청 주기 (관리자가 정한 주기마다 웹이 대신 요청, 위에서 고른 점검 분야). 요청 없이 서버가 보낸 리포트는 받지 않습니다.
· 에이전트 데몬은 10초마다 웹 서버를 확인하므로 요청이 서버에 전달되기까지 최대 10초, 점검에 10~30초 걸립니다. 진행 중에는 5초마다 자동으로 확인합니다.
· 서버 직접 점검은 svr_collect_client 1.12 이상에서 됩니다. 로그 대부분은 root 만 읽을 수 있으므로 클라이언트를 root 로 실행해야 전체 내용이 나옵니다.
· 1.11 이하 서버는 웹에 이미 수집된 자료(자원, 서비스·프로세스 상태, 서버 로그 화면의 마지막 수집본, 알람, 제어 이력)로 웹 기본 리포트를 바로 만듭니다.
· 점검 항목 : 보안(SSH 로그인 실패·IP, sudo / su, 방화벽 차단) · 자원(디스크, 커널 메시지·OOM, Load / vmstat / iostat / sar) · 서비스(★ 웹이 관리하는 서비스·프로세스, cron, 웹·메일 서버) · 변경(패키지·패치, 최근 7일 /etc)
