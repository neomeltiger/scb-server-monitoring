· 가입 신청자는 승인 전에는 로그인할 수 없습니다. 승인 시 권한(일반 사용자 / 관리자)을 선택합니다.
· 일반 사용자(USER)는 조회만 가능하며, 수정·삭제·제어·웹 콘솔·사용자 관리는 관리자(ADMIN)만 가능합니다.
· 자기 자신과 마지막 관리자는 사용 중지 / 권한 내림 / 삭제할 수 없습니다.
· 계정 생성 : 관리자가 바로 만든 계정은 임시 비밀번호가 한 번만 표시되고, 그 사용자는 첫 로그인 때 비밀번호를 바꿔야 합니다. 만든 뒤 [메뉴 권한 부여] 로 그 사용자가 볼 메뉴를 정합니다 (지정하지 않으면 일반 사용자 기본 권한).
