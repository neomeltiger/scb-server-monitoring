에이전트 토큰

아래 두 줄을 서버의 /shared/opt/agent/svr_collect_client/etc/client.env 에 넣으세요. 토큰은 지금만 표시되며 다시 볼 수 없습니다. (분실 시 재발급)

SCB_WEB_URL 은 서버에서 접속할 수 있는 이 웹 서버 주소여야 합니다. (서버에서 localhost 는 서버 자신)

  1. cd /shared/opt/agent && tar xf svr_collect_client.tar
  2. cd svr_collect_client && cp etc/client.env.sample etc/client.env (처음 한 번) 후 vi etc/client.env 에 위 두 줄 입력, chmod 600 etc/client.env
  3. 확인: bin/scb_client.sh ping → ok server_id=... (연결 실패면 서버에서 ping 웹서버IP, 웹 서버 PC 방화벽의 포트 허용 확인)
  4. 데몬 시작: bin/scb_client.sh start (상태 status / 정지 stop) - crontab 사용 안 함
  5. 재부팅 시 자동 시작: cp etc/scb_client.init /etc/init.d/scb_client 후 ln -s /etc/init.d/scb_client /etc/rc3.d/S99scb_client
  6. 자료 수집 시작/중지, 수집 주기, 데몬 종료는 웹 에이전트 관리 화면에서 합니다.
