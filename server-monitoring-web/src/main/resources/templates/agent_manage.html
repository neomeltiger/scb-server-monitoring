사용 안내

웹에서 하는 일 관리자
  • [시작] 자료 수집을 시작(재개)합니다.
  • [중지] 자료 수집을 멈춥니다. 데몬은 계속 살아 있어 언제든 [시작] 할 수 있습니다. (서비스 제어 명령은 계속 처리)
  • [종료] 서버의 데몬 프로세스를 끝냅니다. 종료 후에는 웹에서 다시 켤 수 없으니 서버에서 시작하세요.
  • 수집 주기 : 10초 / 30초 / 1분 / 2분 / 5분 / 10분 - 데몬이 다음 확인 때(최대 10초) 적용합니다.
서버에서 하는 일 (root)
  • 시작 : /shared/opt/agent/svr_collect_client/bin/scb_client.sh start
  • 상태 : bin/scb_client.sh status / 정지 : bin/scb_client.sh stop
  • 서버 재부팅 시 자동 시작 : etc/scb_client.init 을 /etc/init.d/scb_client 로 복사하고 /etc/rc3.d/S99scb_client 링크 (crontab 사용 안 함)
